## housetask

Housetask is an app that ensure housework would be assigned by whom live under the roof indivisually.

## Features

- Add tasks in the household need to be completed
- User can choose tasks 
- Once tasks completed, user can click and mark done.

## Built with

- Node.js and Express
- MongoDB with Mongoose
- EJS templates
- Plain JavaScript and CSS
